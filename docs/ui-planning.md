## Pages

### Home
- App title and short introduction
- Login and register links
- Link to My Books after login

### My Books
- Page title
- Add Book button
- Status filter
- List of books
- Each book shows title, author and status
- Edit and Delete actions

### Add and Edit Book
- Title input
- Author input
- Reading status selection
- Save and Cancel buttons
- Show validation messages

## Design Guide

We will start with Bootstrap.

- Keep the pages simple and clear.
- Use the same buttons and spacing.
- Use readable text and clear labels.
- Make forms easy to use.
- Show errors near the form fields.
- Use a simple status label for each book.
- Test the layout on phones and computers.
- Do not use color alone to show reading status.
